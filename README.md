Laman konsep frontend untuk meneroka identiti Ayam Gepuk Pokmi. Ia dibina dengan React, TypeScript, Vite dan Tailwind CSS; tiada aliran pesanan atau pembayaran sebenar dalam repo ini.

## Apa yang tersedia

- Hero jenama, navigasi seksyen dan animasi scroll.
- Tiga kad menu konsep dengan butiran hidangan dalam modal.
- Pilihan tahap sambal interaktif dan galeri dengan lightbox.
- Pemilih lokasi konsep untuk memaparkan cawangan, waktu dan nombor contoh.
- Susun atur responsif untuk desktop dan telefon.

## Jalankan secara lokal

```bash
npm ci
npm run dev
npm run build
npm run preview
```

`package.json` belum menyediakan skrip ujian automatik. Semak interaksi dan paparan secara manual selepas menjalankan aplikasi.

## Struktur

- `src/App.tsx` — kandungan, data demo dan interaksi halaman.
- `src/index.css` — gaya global.
- `public/og-image.jpg` — gambar preview pautan.
- `PANDUAN_SETUP_MCP.md` — nota setup yang berasingan daripada pengalaman laman.

## Had

Nama cawangan, alamat, waktu operasi dan nombor telefon yang dipaparkan ialah **placeholder demo**, bukan butiran kedai sebenar. Foto makanan menggunakan imej luaran Unsplash. Butang sosial berlabel demo tidak membuka akaun rasmi.
